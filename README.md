# EPAM project - 26
 
Repository for submitting the EPAM Student Assignments as part of the program.
 
## Guidelines
 
- All assignments must be uploaded to this GitHub repository: **EPAM project - 26**.
- Each assignment has its own dedicated duration — complete it within the given timeframe.
- A submission form will be shared for every individual assignment.
- **Deadline:** All assignments must be uploaded to this repository before **20-Aug**.
- Students who do not submit all assignments on time will **not be eligible for the interview**.
